# Branding assets

The Trilium name and logo belong to the Trilium Notes project. They are used here because this is a
client *for* Trilium, and the alternative — inventing a look-alike mark — would be more misleading,
not less.

| File | Origin |
|---|---|
| `trilium-icon-color.svg` | [`apps/website/src/assets/icon-color.svg`](https://github.com/TriliumNext/Trilium/blob/main/apps/website/src/assets/icon-color.svg) |
| `trilium-icon-1024.png` | [`apps/desktop/electron-forge/app-icon/png/1024x1024.png`](https://github.com/TriliumNext/Trilium/blob/main/apps/desktop/electron-forge/app-icon/png/1024x1024.png) |

Both are from [TriliumNext/Trilium](https://github.com/TriliumNext/Trilium), which is licensed
AGPL-3.0-only — the same licence this project uses, so redistribution is compatible.

**Trademark is a separate matter.** AGPL-3.0 §5(e) explicitly withholds any grant of rights in trade
names or trademarks. Using the mark for a personal client pointed at your own server is ordinary
nominative use. Distributing a build under the Trilium name or logo would imply endorsement by the
upstream project, which is a question for whoever ships it rather than a licensing one.

Regenerate the raster sizes with `apps/web/`'s copy of this set, or from the 1024 master with `sips`.
